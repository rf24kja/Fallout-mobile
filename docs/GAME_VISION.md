# Game Vision — Wasteland RPG Prototype

## Product Statement

**An original, serious, cinematic mobile-first post-apocalyptic RPG with Fallout 2-level systemic design quality.**

This is **our own product** with:
- Original world, lore, and setting
- Original visual assets and art direction
- Original characters, factions, and settlements
- Original names, terminology, and branding
- Original UI/UX designed for mobile
- Original final presentation

**But** with mechanics, systemic depth, combat logic, balancing discipline, and quest-design quality inspired by the best qualities of Fallout 2.

---

## Core Design Pillars

### 1. Tactical Turn-Based Combat
- Meaningful AP economy — every action point matters
- Strong weapon identity — each weapon class has a distinct tactical role
- Meaningful ammo differences — ammo type changes weapon behavior
- Armor with real tactical value — DR/DT system that creates meaningful choices
- Positioning, cover, and facing matter
- Enemy AI that uses tactics, not just stats

### 2. Deep Character Progression
- SPECIAL-equivalent primary attributes that gate everything
- Skills relevant in combat AND non-combat (dialogue, crafting, exploration)
- Perks that enable new playstyles, not just +% bonuses
- Derived stats (HP, AP, carry weight, crit chance) calculated from attributes
- Level-up choices that feel impactful

### 3. Consequence-Driven Quest Design
- Multiple resolution paths per quest (combat, stealth, dialogue, science, repair, etc.)
- Skill-gated dialogue options that feel earned
- Persistent world reactivity — choices change the world state
- Moral ambiguity — no "good/evil" meter, only consequences
- Rewards tied to playstyle and approach

### 4. Systemic Itemization
- Structured weapon progression with clear roles
- Ammo economy that matters (scarcity, variety, specialization)
- Armor tiers with tradeoffs (weight vs protection vs mobility vs stealth)
- Healing items with tactical timing considerations
- Utility items that enable creative solutions

### 5. World Reactivity
- Faction reputation that gates content and changes NPC behavior
- Time-sensitive events and consequences
- Dynamic encounters that respond to player level and choices
- Persistent world state (looted containers stay looted, dead NPCs stay dead)

## What We Are NOT

| We Are NOT | We ARE |
|------------|--------|
| A 1:1 Fallout 2 clone | An original IP with original content |
| A literal remaster | A modern mobile-first RPG |
| A casual mobile game with Fallout skin | A serious, mature, gritty RPG |
| A game with random simplified mechanics | A game with Fallout 2-level systemic depth |
| A placeholder-filled prototype | A production-quality vertical slice |

---

## Reference Standard: Fallout 2

We use Fallout 2 as a **design benchmark** for:

| System | What to Benchmark |
|--------|-------------------|
| Combat Pacing | Turn length, AP costs, action economy |
| Weapon Progression | Tier structure, unique roles, upgrade paths |
| Armor Usefulness | DR/DT balance, weight/mobility tradeoffs |
| Ammo Design | Caliber variety, special ammo types, economy |
| Skill Relevance | Combat + non-combat checks, gating |
| Quest Branching | Multiple solutions, skill checks, consequences |
| Item Economy | Scarcity, value, weight, utility |
| Balance Discipline | No dominant strategies, rock-paper-scissors |

**We do NOT copy content.** We copy **design quality**.

## Target Audience

- Core RPG players on mobile (ages 18+)
- Fans of classic isometric RPGs (Fallout 1/2, Baldur's Gate, Planescape Torment, Wasteland 2/3, Underrail, Age of Decadence)
- Players seeking depth on mobile — not "mobile game depth," real RPG depth
- Willing to pay premium for quality (no F2P, no ads, no microtransactions)

---

## Platform & Technical Constraints

- **Primary**: Android (API 36+), iOS (iOS 15+)
- **Engine**: Godot 4.7.2 (C# or GDScript)
- **Rendering**: Modern isometric, cinematic lighting, post-processing
- **Controls**: Touch-first, gamepad/keyboard support
- **Offline**: Fully playable offline
- **Save System**: Multiple slots, cloud sync optional

---

## Monetization

**Premium single purchase.** No IAP, no ads, no battle passes, no currency.
One-time buy = full game. DLC/Expansions as substantial content drops only.

---

## Success Criteria (Vertical Slice)

1. **One complete location** with original art, 3-5 quests, 10+ NPCs
2. **Combat encounter** demonstrating full tactical depth
3. **Character creation + progression** through level 5
4. **Inventory + itemization** with 20+ original items
5. **Dialogue system** with branching, skills, consequences
6. **Save/Load** working across all systems
7. **60 FPS** on mid-range mobile (Snapdragon 7 Gen 1 / A14 Bionic)
8. **< 500 MB** install size
9. **< 3 sec** cold start

---

## Development Philosophy

> "Don't ask what Fallout 2 did. Ask *why* it worked, then build our own system that achieves the same design goal."

Every system must pass the **Fallout 2 Test**: *Would this design decision hold up in Fallout 2?* If not, iterate until it does.
